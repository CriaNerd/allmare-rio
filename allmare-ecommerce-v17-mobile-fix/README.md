# ALLMARE Ecommerce V17 — correção mobile

Baseada na V16, mantendo o mesmo visual e coleção.

## Correção principal
- O botão **Escolher** no mobile agora abre a seção de compra de forma confiável.
- A área de compra não pode mais ficar invisível por causa da animação `reveal`.
- Seleção M / G / GG, quantidade e adicionar à sacola continuam visíveis em telas pequenas.
- Scroll até a compra considera o cabeçalho fixo.
- Desktop e admin mantidos.

## Render
Root Directory: `allmare-ecommerce-v17-mobile-fix` (caso a pasta inteira seja enviada ao repositório)
Build Command: `npm install`
Start Command: `npm start`
